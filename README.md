# ☁️ CloudStorage

Веб-приложение для сохранения файлов на локальный ПК с доступом с любого устройства через браузер. Работает по HTTPS с самоподписанным сертификатом, поддерживает многопользовательский режим с ролями, журналирование и адаптивный интерфейс.

## 📖 О проекте

**CloudStorage** — это self-hosted решение для организации личного облачного хранилища на Windows-ПК. Приложение запускается локально и открывает веб-интерфейс, доступный как из локальной Wi-Fi сети, так и извне. Основное назначение — быстрая загрузка файлов с мобильных устройств (iOS/Android), ноутбуков и других ПК в заранее заданные каталоги на диске сервера.

Проект создавался как альтернатива публичным облачным сервисам с полным контролем над данными: файлы не покидают вашу машину, доступ защищён HTTPS с самоподписанным сертификатом, а все действия пользователей фиксируются в журнале.

### Основные сценарии использования

- 📱 Быстрая перекидка фото/видео с iPhone на ПК без проводов и iTunes
- 💾 Резервное копирование документов с любых устройств в структурированные каталоги
- 🗂️ Организация личного файлового архива с журналом загрузок
- 👨‍👩‍👧 Семейное хранилище с раздельными аккаунтами

## ✨ Возможности

### Загрузка файлов
- ✅ **Множественная загрузка** — выбор нескольких файлов за раз
- ✅ **Drag & Drop** — перетаскивание файлов в зону загрузки
- ✅ **Поддержка кириллицы** — имена файлов сохраняются в оригинале (`Оферта_ВЕРАТЕК.docx`)
- ✅ **Защита от перезаписи** — при совпадении имён добавляется суффикс `(1)`, `(2)`
- ✅ **Прогресс загрузки** — визуальный прогресс-бар с процентами и скоростью

### Управление каталогами
- 📁 **Каталог по умолчанию** — `NOSORT` для неотсортированных файлов
- 📂 **Выбор существующего каталога** из выпадающего списка
- ➕ **Создание новых каталогов** прямо из интерфейса с подтверждением
- ⚠️ **Предупреждение** при попытке загрузить в несуществующий каталог

### Информация о диске
- 💾 Отображение **общего объёма** диска хранения
- 📊 Отображение **занятого и свободного места** с процентным соотношением
- 📈 **Визуальный прогресс-бар** заполнения диска
- 🔄 Автоматическое обновление каждые 30 секунд
- 🧮 Предварительный **расчёт объёма** выбранных файлов

### Безопасность и аутентификация
- 🔐 **Локальные пользователи** с хэшированием паролей (PBKDF2-SHA256)
- 📧 **Привязка к email** для восстановления пароля
- ⏱️ **Автовыход через 15 минут** неактивности с живым таймером
- 👑 **Роли**: администратор и обычный пользователь
- 🔒 **HTTPS** с самоподписанным сертификатом
- 🍪 Защищённые cookie (HttpOnly, Secure, SameSite)

### Журналирование
- 📋 **Полный журнал действий**: кто, когда, что и куда загрузил
- 🔍 **Поиск по журналу** — по имени файла, пользователю, пути
- 📄 **Пагинация** — 50 записей на страницу
- 📊 Фиксация размера, типа файла, IP-адреса и User-Agent
- 📁 Логирование создания каталогов и управления пользователями

### Интерфейс
- 🎨 **Тёмная тема** без ярких цветов
- 📱 **Адаптивный дизайн** — ПК, ноутбуки, планшеты, смартфоны
- 👆 **Тач-дружелюбный** — увеличенные кнопки для мобильных
- 🌐 **Навигация**: Облако, Журнал, Администрирование (только для админа)

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/username/CloudStorage.git
cd CloudStorage
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

**requirements.txt:**

```
Flask==3.1.3
Flask-Login==0.6.3
Flask-WTF==1.3.0
Werkzeug==3.1.8
```

### 4. Создание SSL-сертификата

```bash
mkdir certs
cd certs
openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes -subj "/C=RU/ST=Region/L=City/O=CloudStorage/OU=IT/CN=localhost"
cd ..
```

### 5. Создание структуры каталогов

```bash
mkdir database logs uploads certs
mkdir CLOUD
mkdir CLOUD\NOSORT
```

### 6. Запуск приложения

```bash
python app.py
```

Приложение будет доступно:
- **Локально**: https://localhost:443
- **По сети**: https://<IP-адрес-ПК>:443

## ⚙️ Конфигурация

Основные настройки в файле `config.py`:

```python
class Config:
    BASE_DIR = os.path.dirname(os.path.abspath(__file__))
    DATABASE_PATH = os.path.join(BASE_DIR, 'database', 'cloud_storage.db')
    
    # Корневой каталог для хранения файлов
    CLOUD_ROOT = os.path.join(BASE_DIR, 'CLOUD')
    # Или на отдельном диске:
    # CLOUD_ROOT = r'F:\CLOUD'
    
    DEFAULT_UPLOAD_FOLDER = os.path.join(CLOUD_ROOT, 'NOSORT')
    
    # Таймаут сессии (минуты)
    SESSION_TIMEOUT = 15
    
    # Максимальный размер запроса (1 ГБ)
    MAX_CONTENT_LENGTH = 1024 * 1024 * 1024
    
    # Хост и порт
    HOST = '0.0.0.0'
    PORT = 443  # или 8443, если 443 занят
```

### ⚠️ Важно при указании путей

Всегда используйте **raw-строки** (`r'...'`) для Windows-путей, чтобы избежать ошибок с escape-последовательностями:

```python
# ✅ Правильно
CLOUD_ROOT = r'F:\CLOUD'

# ❌ Неправильно — вызовет SyntaxError
CLOUD_ROOT = 'F:\CLOUD'
```

И помните: **кириллическая `С` ≠ латинская `C`** — визуально они почти одинаковы!

## 🖥️ Ярлык для быстрого запуска

### Вариант 1: Batch-файл

Создайте `start_cloud.bat`:

```batch
@echo off
chcp 65001 >nul
title CloudStorage Server
cd /d "%~dp0"
call .venv\Scripts\activate.bat
python app.py
pause
```

### Вариант 2: VBS (без окна консоли)

Создайте `start_cloud.vbs`:

```vbscript
Set WshShell = CreateObject("WScript.Shell")
WshShell.Run "cmd /c cd /d """ & CreateObject("Scripting.FileSystemObject").GetParentFolderName(WScript.ScriptFullName) & """ && call .venv\Scripts\activate.bat && python app.py", 0, False
```

### Остановка сервера

Создайте `stop_cloud.bat`:

```batch
@echo off
taskkill /f /im python.exe >nul 2>&1
echo Server stopped
timeout /t 2 >nul
```

### Рекомендации для production

1. **Смените пароль администратора** после первого входа

## 🐛 Устранение неполадок

### `FileNotFoundError: [WinError 3] 'С:\\'`

**Причина**: кириллическая буква `С` в пути вместо латинской `C`.

**Решение**: используйте `os.path.join(BASE_DIR, 'CLOUD')` или проверьте кодировку:

```python
python -c "from config import Config; print(repr(Config.CLOUD_ROOT))"
```

### `SyntaxError: (unicode error) 'unicodeescape'`

**Причина**: обратные слеши в пути без raw-строки.

**Решение**: добавьте `r` перед строкой: `r'C:\Users\...'`

### `PermissionError: [WinError 10013]` на порту 443

**Причина**: порт 443 требует прав администратора.

**Решение**:
- Запустите PyCharm/терминал от имени администратора
- Или измените `PORT = 8443` в `config.py`

### `[Errno 10048] address already in use`

**Причина**: порт занят другим процессом.

**Решение**:

```cmd
netstat -ano | findstr :443
taskkill /f /pid <PID>
```

### iOS не подключается по HTTPS

**Причина**: самоподписанный сертификат не доверен.

**Решение**:
1. Откройте `https://<IP-ПК>:443` в Safari
2. Нажмите «Дополнительно» → «Перейти на сайт»
3. Для постоянного доверия: настройки → Основные → Об этом устройстве → Доверие сертификатам

### Браузер не открывает сайт по IP с другого устройства

**Причина**: брандмауэр Windows блокирует порт.

**Решение**:

```cmd
netsh advfirewall firewall add rule name="CloudStorage 443" dir=in action=allow protocol=TCP localport=443
```

Или разрешить Python в диалоге брандмауэра при первом запуске.
